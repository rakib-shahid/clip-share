# Slice 2.20: Collapsed explorer Breadcrumb

## Status and outcome

**Completed September 12, 2026. Parent: main spec 2. Depends on 2.11 and 2.16.** Replaced handwritten
breadcrumb markup with the official Breadcrumb and an overflow menu.

## Work

- Add the shadcn Breadcrumb source and render `<nav aria-label="Breadcrumb">`.
- With four or fewer crumbs, show all. With more, show root, ellipsis, parent,
  and current; the ellipsis Dropdown Menu lists omitted ancestors root-to-leaf.
- Ancestors navigate through the explorer loader. Current is BreadcrumbPage and
  cannot trigger a redundant request. Separators are hidden from screen readers.
- Keep administrator **All libraries** as a separate preceding Button because it
  exits the folder hierarchy. Truncate visually while preserving accessible and
  Tooltip text for the full folder name.

## Verification

Tests cover root/short/long paths, exact collapse membership/order, duplicate
names with distinct IDs, menu keyboard access, ancestor navigation, no current
request, admin Back behavior, long names, and 320 px containment.

## Implementation evidence

- The pinned shadcn Breadcrumb source is recorded in the registry and composes
  with Dropdown Menu and Tooltip. Paths over four crumbs show root, an ordered
  ancestor menu, parent, and inert current page.
- All libraries remains a separate Button; full names remain accessible while
  constrained markup prevents narrow-screen overflow.
- Focused tests cover root/short/long paths, duplicate-name IDs, exact collapse,
  keyboard menu focus, navigation, Back, current-page inertness, and long names.
