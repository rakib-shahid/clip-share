# Slice 2.2: Radix-backed shadcn Dialog primitive

## Status and outcome

**Completed September 12, 2026. Parent: main spec 2. Depends on 2.1.** The
official shadcn Dialog source is installed and characterized before consumer
migration.

## Work

- Add `web/src/components/ui/dialog.tsx` through the pinned registry workflow.
- Theme only through accepted tokens/classes; preserve upstream focus scope,
  portal, overlay, title, description, close, Escape, and outside-interaction
  behavior.
- Expose upstream composition parts rather than recreating the old `Modal` prop
  API. Busy consumers will control `open` and prevent close explicitly.

## Verification

Component tests cover initial focus once per open, Tab/Shift+Tab containment,
Escape and overlay close, labelled title/description, close-button name, nested
topmost behavior, and focus restoration. A parent rerender with a new callback
identity must not refocus the dialog.

## Implementation evidence

- The shadcn `4.21.0` registry output is installed as
  `web/src/components/ui/dialog.tsx`, themed with the accepted semantic tokens,
  and recorded in the registry manifest.
- `@radix-ui/react-dialog` `1.1.23` and `tw-animate-css` `1.4.0` are pinned. The
  root TypeScript alias now mirrors the application config so future Windows CLI
  additions resolve `@/` into `web/src` rather than a literal directory.
- Five focused Dialog tests cover every verification behavior, including title-
  input focus across controlled parent rerenders and topmost nested Escape.
- Frontend lint, all 18 unit tests, host production build, and a clean Docker
  `web-build` target passed on September 12, 2026.
