# Slice 2.15: Store-level folder sorting

## Status and outcome

**Completed September 12, 2026. Parent: main spec 2. Depends on 2.14.** `Store.FolderPage` now applies
each accepted order across the complete folder while retaining combined paging.

## Work

- Pass a typed options value containing sort and decoded keyset; migrate internal
  callers.
- Keep folders as the first group. Apply name descending to folders only for
  `name_desc`; every other mode uses normalized name/ID ascending.
- Implement the clip orders exactly as the main table. Null sizes sort after
  known sizes in both directions. State uses an explicit SQL CASE and then
  creation time/ID descending.
- Select only whitelisted static `ORDER BY` fragments; never interpolate request
  text. Pair every order with its static lexicographic seek predicate.
- Preserve at most 60 combined items and the folder-to-clip boundary. Return
  authoritative `totalFolderCount`, `totalClipCount`, and `totalItemCount` for
  direct visible children. Visible folders are non-deleted; visible clips are
  non-deleted except `uploading` and `cancelled`, with failed notices included.
  Folder-card clip counts use the same state filter. Preserve breadcrumbs,
  authorization lookup behavior, and empty arrays.

## Verification

Store tests use more than 60 mixed items and ties for normalized names, times,
sizes, null sizes, states, and IDs. For every sort, concatenated pages contain
each item once in exact order with no gap/duplicate at the group boundary.
Mutation tests insert/delete before a cursor without shifting later pages and
verify all three totals and folder-card counts against every clip state.

## Implementation evidence

- `FolderPageOptions` carries the closed sort and decoded cursor, with static
  order/seek branches for all seven modes and strict folder-first keyset paging.
- Responses expose the three authoritative direct-child totals, include failed
  clips, and use the same visible-state rule for folder cards.
- Store coverage exercises 75 tied clips through every sort plus the exact
  60-folder/clip phase boundary. `go test ./...` passes.
