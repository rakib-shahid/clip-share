# Slice 2.29: Upload Attachment presentation

## Status and outcome

**Completed September 13, 2026. Parent: main spec 2. Depends on 2.2, 2.8, and 2.12.** Uses shadcn
Attachment for the selected source and its transient lifecycle inside Upload
Dialog.

## Work

- Add the official Attachment source. Show selected filename, detected type or
  generic Video, byte size, poster/local media only where already safe, and a
  labelled remove/replace action before transfer.
- Migrate the standard and editor-opening Upload Dialog shells from custom Modal
  to Dialog; its destructive cancel confirmation was migrated in slice 2.8.
- Map idle/uploading/processing/error/done only to states the upload flow actually
  knows. Use Progress for measured transfer and Spinner/text for validation or
  analysis; never reuse the last transfer percentage as processing progress.
- Preserve native file input/drop behavior, validation, object-URL cleanup,
  cancellation, editor/direct-upload branching, and privacy language.

## Verification

Tests cover keyboard file selection, drop, replace/remove, every lifecycle,
measured versus indeterminate progress, error/retry/cancel, object URL revocation,
long filenames, accessible action labels, and no source path disclosure.
