# Slice 2.24: Item Dropdown and Context Menu actions

## Status and outcome

**Completed September 13, 2026. Parent: main spec 2. Depends on 2.7, 2.11, and 2.21–2.23.** Replaced
ItemManagementBar with one shared action descriptor consumed by two shadcn menus.

## Work

- Add the official Context Menu source. Build action descriptors with stable ID,
  label, icon, group/separator, destructive flag, and handler/dialog intent.
- Produce the exact main-spec action matrix for folder, ready, active, and failed
  items. Dropdown and Context Menu render the same descriptor list.
- Right-click, Menu key, and Shift+F10 open Context Menu on the focused item;
  visible three-dot Dropdown remains available to all pointers.
- Copy link awaits clipboard completion, announces success, and emits Sonner;
  failures stay inline or in a destructive toast and never claim success. Public
  page opens safely in a new tab. Mutation actions open their existing Dialog.
- After a successful mutation, reload page one under the committed sort. If the
  acted-on item remains, restore focus to its overflow trigger. If removal keeps
  a successor at the old index, focus that item's primary action; otherwise use
  the preceding item, then the collection heading/empty-state primary action.
  Never retain focus on a detached menu node.

## Verification

Table tests compare both menus' labels/order for every role/state. Interaction
tests cover mouse/keyboard, focus return, event isolation, exactly-once handlers,
clipboard failure, safe new tab, omitted actions, destructive styling, and no
custom long press. Mutation tests cover retained, reordered, removed-last,
removed-middle, and now-empty focus placement.
