# Slice 2.5: Application content Dialog migrations

## Status and outcome

**Completed September 12, 2026. Parent: main spec 2. Depends on 2.2.** Read and
browse surfaces use the shared Dialog without folding domain logic into the
primitive.

## Work

- Migrate clip/video preview, Search, Recycle bin, and Manage users shells to
  Dialog composition.
- Preserve maximum sizes, bounded scrolling, media controls, nested preview,
  search focus, current request timing, retry paths, and administrator context.
- The primitive owns portal/focus/dismissal only; each feature continues to own
  loading, data, mutation, and authorization state.

## Verification

Test each opener's focus return, nested preview topmost behavior, scrollable
content at 320 px and desktop, Escape/outside close, media keyboard access, and
unchanged loading/error requests.

## Implementation evidence

- Clip/video preview, Search, Recycle bin, and Manage users shells now compose
  `DialogContent`, labelled headers, descriptions, and bounded viewport scroll.
- Video controls receive initial focus; Search retains its input autofocus; all
  conditionally mounted shells restore focus to their exact opener.
- Nested Search and Recycle-bin previews use Radix layering so Escape closes only
  the topmost content surface.
- Four focused migration tests cover media focus, nested behavior, request
  preservation, bounded content, Escape, and focus restoration.
