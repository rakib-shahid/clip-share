# Slice 2.9: Responsive dialog hook and Drawer primitive

## Status and outcome

**Completed September 12, 2026. Parent: main spec 2. Depends on 2.1 and 2.2.** A
reusable media-query hook and the official Drawer foundation are installed.

## Work

- Add `useMediaQuery` with `matchMedia` subscription/cleanup and an SSR-safe
  fallback; derive `useIsNarrow` from `(max-width: 639px)`.
- Add the official shadcn Drawer source through the pinned registry. Drawer is
  backed by Vaul; this is the accepted provider exception and does not replace
  Radix for Dialog, Alert Dialog, menus, Tooltip, or focus primitives.
- Create no universal responsive-modal abstraction. Consumers explicitly render
  Dialog or Drawer so their semantics and focus targets remain reviewable.

## Verification

Hook tests cover initial match, changes, legacy-listener absence, cleanup, and
unavailable `matchMedia`. Drawer tests cover title/description, focus, swipe or
close behavior supplied upstream, busy controlled-open behavior, and 320 px fit.

## Implementation evidence

- `useMediaQuery` and `useIsNarrow` provide SSR-safe initial state, modern event
  subscription, live updates, and cleanup at the accepted 639px boundary.
- Vaul `1.1.2` is pinned; the official Drawer source uses accepted overlay,
  background, border, and viewport-size tokens.
- Four focused hook/Drawer tests pass, including controlled busy behavior and
  narrow viewport containment.
