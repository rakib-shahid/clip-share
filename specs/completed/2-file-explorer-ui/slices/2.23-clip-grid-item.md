# Slice 2.23: Clip grid item and processing states

## Status and outcome

**Completed September 13, 2026. Parent: main spec 2. Depends on 2.12, 2.18, and 2.21.** Replaced the
custom clip-card/action-bar shell with one Item-based grid representation.

## Work

- Ready items show lazy 16:9 poster, title, Ready Badge, formatted stored size,
  and RelativeUploadTime. Their primary button opens preview once.
- Queued/validating/processing items show icon artwork, exact text state, upload
  date, and Progress only for a finite server value clamped for rendering while
  announcing the original valid 0–100 contract. Otherwise show Spinner/status.
- Failed items show Failure Badge and safe error text. Non-ready items have no
  preview button. All states reserve stable media/content geometry.
- Overflow remains a separate action slot; no video element loads in the card.

## Verification

Tests cover every state/null combination, poster URL/alt behavior, lazy loading,
preview eligibility, progress ARIA, non-color status, long titles/errors,
overflow isolation, and no eager media request.
