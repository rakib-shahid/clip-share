# Slice 2.31: Recycle-bin item convergence

## Status and outcome

**Completed September 13, 2026. Parent: main spec 2. Depends on 2.5–2.8, 2.12, and 2.17.** Reuses the
accepted item/state/menu language in Recycle bin without changing retention.

## Work

- Preserve API most-recently-deleted order; add no sort control. Store grid/list
  preference independently from Explorer and Search.
- Use Item/ItemGroup, Empty, Skeleton, Badge, Tooltip, Dropdown Menu, and Context
  Menu for trashed folders/clips. Clip preview remains private and authorized.
- Actions are Preview (clips), Restore, and administrator-only Delete permanently,
  with matching visible/context ordering. Restore success uses Sonner plus the
  existing library refresh. Purge uses the migrated acknowledged Alert Dialog.
- Show deletion/expiry metadata already available; do not invent folder size or
  reveal private paths.

## Verification

Tests cover order, empty/loading/error, grid/list persistence, both menus,
normal/admin action eligibility, nested preview, restore refresh/toast/error,
purge acknowledgement/busy/error, focus return, and 320 px layout.
