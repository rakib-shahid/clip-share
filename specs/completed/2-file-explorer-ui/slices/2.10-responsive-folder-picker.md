# Slice 2.10: Responsive folder picker

## Status and outcome

**Completed September 12, 2026. Parent: main spec 2. Depends on 2.5 and 2.9.**
The folder picker renders as Dialog on desktop and bottom Drawer below 640px.

## Work

- Share one picker body/state between the two shells; never duplicate browsing,
  exclusion, acting-user, error, or selection logic.
- Preserve breadcrumb navigation, administrator owner switching, excluded source
  folder, asynchronous confirmation, error/retry, and nested usage.
- On a responsive shell change while open, preserve current folder and error
  state, then move focus to the equivalent control without firing `onChoose`.

## Verification

Tests cover both breakpoints, live breakpoint change, owner contexts, exclusions,
empty/loading/error folders, busy close prevention, exactly-once choose, and
focus return to the move/copy/upload/editor opener.

## Implementation evidence

- One parent-owned state machine supplies a shared picker body to explicit
  Dialog and Drawer shells, preserving browsing state across live shell changes.
- Owner switching, breadcrumbs, exclusions, empty/loading/error presentation,
  busy dismissal, and exactly-once async selection are retained.
- Three focused tests cover desktop, narrow, live breakpoint change, exclusion,
  state retention, and duplicate activation.
