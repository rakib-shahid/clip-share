# Slice 2.18: Relative upload-time presentation

## Status and outcome

**Completed September 12, 2026. Parent: main spec 2. Depends on 2.12.** Added one shared formatter/hook
and semantic display component for clip creation time.

## Work

- Parse the API timestamp once, render semantic `<time dateTime>` and compact
  locale-aware relative buckets, including `Yesterday` and short dates for old
  items.
- Put the exact localized date/time in Tooltip and accessible text.
- Refresh minute/hour buckets no more than once per minute while visible. Pause
  when `document.hidden`, resume/recompute on visibility change, and clean up.
- Invalid/missing timestamps render `Upload date unavailable`, no Tooltip, and
  never affect server sorting.

## Verification

Fake-time tests cover future clock skew, seconds/minutes/hours/yesterday/date
boundaries, locale-safe output assertions, exact Tooltip, visibility pause,
timer cleanup, invalid input, and no per-item timer multiplication.

## Implementation evidence

- `RelativeUploadTime` renders a keyboard-accessible semantic `time`, exact
  localized tooltip/name, compact locale-aware buckets, and a plain invalid
  fallback; current clip cards consume it.
- All mounted timestamps share one minute ticker. It stops while the document is
  hidden, recomputes on return, and is removed after the final subscriber.
- Boundary, tooltip, invalid-input, visibility, shared-timer, and cleanup tests
  pass with ESLint and the production build.
