# Slice 2.19: Explorer toolbar and controls

## Status and outcome

**Completed September 12, 2026. Parent: main spec 2. Depends on 2.11, 2.16, and 2.17.** Added the
responsive creation, view, and server-sort controls.

## Work

- Add official Button Group and Toggle Group sources through the pinned registry.
- Group New folder and Upload clip without merging their actions. Preserve their
  existing disabled rule until a folder is loaded.
- Present the page title with the server-provided direct-child summary using
  `totalFolderCount` and `totalClipCount`; omit neither zero and use correct
  singular/plural labels. `totalItemCount` is the authoritative empty-state
  check, not the length of the currently loaded page.
- Render Grid/List as a single-selection labelled Toggle Group. Switching view
  writes preference and changes layout without fetching.
- Render the seven sort choices as one labelled Dropdown Menu radio group.
  Selecting the active sort is a no-op; selecting another writes preference,
  discards prior cursors, and requests page one with that enum.
- Wrap controls below 640 px; never horizontally scroll or hide their labels
  from assistive technology. Toolbar remains non-sticky.

## Verification

Tests cover defaults/restored preferences, each control, no duplicate actions,
sort request encoding, stale cursor removal, busy/disabled state, keyboard/touch,
320 px wrapping, and accessible selected/menu state.

## Implementation evidence

- Pinned Radix-backed shadcn Button Group, Toggle, and Toggle Group sources are
  recorded in the registry manifest; creation actions, Grid/List, and the
  seven-choice sort radio menu now compose the toolbar.
- Preferences follow the acting user. View changes relayout loaded items; sort
  changes issue a cursor-free page-one URL, while Load more carries the current
  sort and encoded keyset.
- The heading uses authoritative totals and correct pluralization, and empty
  state uses `totalItemCount`. Focused control/URL tests, the full frontend
  suite, ESLint, TypeScript, and production build pass.
