# Slice 1.6: Editor shell and accessibility

## Status

**Completed.**

## Contract

The editor uses the shared authenticated modal and becomes full-screen on narrow
viewports. It shows source facts, private-source guidance, destination, trim
duration, mix, compression, and persistent text state. Loading/saving/rendering
uses `role=status`; failures use `role=alert`; icon controls have accessible
names. Focus trapping, Escape, nested-dialog inertness, and return focus follow
the shared modal contract. Space toggles playback throughout the main editor,
except in text inputs or an open nested dialog.

## Verification

Component/browser tests cover keyboard-only use, focus restoration, screen-reader
labels/status, narrow layout, nested confirmations, and Space-key precedence.
