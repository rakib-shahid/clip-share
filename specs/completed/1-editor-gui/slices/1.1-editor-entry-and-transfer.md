# Slice 1.1: Editor entry and source transfer

## Status

**Completed.**

## Contract

- **Upload clip** keeps the direct validate-and-queue path.
- **Trim clip** opens the editor immediately, retains the selected browser
  `File`, and begins the authenticated source transfer and analysis flow.
- The request carries the selected title, destination, and existing compression
  choice and applies the same ownership, uniqueness, source-size, and temporary
  capacity rules as ordinary upload.
- Closing during transfer or analysis routes through confirmation. Cancellation
  removes the partial source, reservation, placeholder, and session state.

## Verification

Component and HTTP tests distinguish the two entry actions, prove the direct
upload does not create an editor session, and cover transfer failure/cancellation
cleanup.
