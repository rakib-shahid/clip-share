# Slice 1.10: Audio-track controls

## Status

**Completed.**

## Contract

Each usable stream shows only probed facts: ordinal, language, codec, layout,
sample rate, and dispositions. Include/Mute and a keyboard-operable -60 to
+12 dB slider use 0.5 dB steps; muting preserves the selected gain. The default
mix enables only the default or first usable stream at 0 dB. All-muted is allowed
and announces `This clip will be silent`. Unusable tracks are informational and
disabled. There is no persisted solo, master meter, normalization, ducking, EQ,
or user-adjustable fade.

## Verification

Component tests cover defaults, mute/unmute gain retention, limits, accessible
labels, unusable rows, and the silent-output message.
