# Slice 1.3: Private editor-session lifecycle

## Status

**Completed.**

## Contract

An opaque, authenticated session owns the hidden placeholder, source,
reservation, recipe revision, preview state, and heartbeat time. It is never
returned by public routes, search, or ready-folder counts. Open editors heartbeat
once per minute. Selecting the same normalized title, destination, and source
byte size can resume the uploader's session for five minutes; another identity
creates an independent session. Five full minutes without a heartbeat expires
the session idempotently. A session can be edited until finalization locks it.

## Verification

Store and HTTP tests cover ownership, admin acting context, resume identity,
expiry, repeat cleanup, hidden public state, and `404` after cleanup.
