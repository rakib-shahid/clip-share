# Slice 1.4: Canonical recipe validation

## Status

**Completed.**

## Contract

The server validates integer millisecond trim bounds with
`0 <= in < out <= duration` and a 250 ms minimum. Audio stream indexes must
belong to the probed source, be usable, and occur once. Include is boolean; gain
is finite, from -60 dB through +12 dB, in 0.5 dB steps. Canonical ordering is by
source stream index. An omitted audio recipe means the default-marked usable
track, or first usable track, at 0 dB—not all tracks. All-muted output is valid.

## Verification

Unit tests cover bounds, quantization, non-finite values, duplicate/foreign
streams, the default mix, silent output, and canonical serialization.
