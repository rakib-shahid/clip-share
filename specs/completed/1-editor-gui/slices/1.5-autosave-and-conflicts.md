# Slice 1.5: Autosave and revision conflicts

## Status

**Completed.**

## Contract

The client debounces whole-recipe saves and sends the last observed revision.
The server advances revisions atomically. A stale save receives
`409 edit_conflict`; the client reloads authoritative state rather than merging
or overwriting it. The editor visibly reports Saving, Saved, and Retry. Title and
destination remain editable before finalization under existing authorization,
uniqueness, folder-picker, and reservation rules. Session autosave is not durable
user draft history.

## Verification

Store, HTTP, and component tests cover successful advancement, stale tabs,
retryable failures, pending-save finalization blocking, and no secret or recipe
data in browser persistence.
