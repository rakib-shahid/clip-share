# Slice 1.9: Source playback and fallback

## Status

**Completed.**

## Contract

Browser-playable sources use a private local object URL for immediate playback
and filmstrip capture; production CSP permits `blob:` media. Playback and seeking
are clamped to the selected range and loop from Out to In, including physical
end-of-media. Selection changes clamp an outside playhead to In. If the original
codec/container is unsupported, the server creates one private full-source
browser-compatible MP4 proxy and uses it for the rest of the session. No object
URL or proxy becomes public.

## Verification

Browser tests cover looping, end-of-media, clamping, local URL revocation,
unsupported-source fallback, private authorization, and CSP behavior.
