# Slice 1.11: Private rendered preview

## Status

**Completed.**

## Contract

Render preview produces an authenticated, `no-store`, H.264/AAC 720p asset at
2 Mbps using the current saved trim/mix graph. It renders the full selection up
to 60 seconds or a playhead-centered 60-second window. Only one preview child job
runs per session. Rendering shows an indeterminate status; no percentage is
invented. A replacement uses a separate pending file, retains the last complete
preview while running, and swaps atomically on success. Failure keeps the editor
and prior preview available with Retry.

## Verification

HTTP/processor tests cover authorization, byte ranges, recipe revision, window
bounds, replacement atomicity, retry, and the absence of public access.
